# joint-log
# 指関節の痛み記録

両手の指の関節のうち、どこが、どのくらい痛んだかを1日1枚の図で記録するWebアプリです。

手の甲の図の関節をタップするだけで記録できます。日によって痛む場所が変わる症状を、あとから見返せる形で残すことを目的にしています。

**→ [アプリを開く](https://saga169.github.io/joint-log/)**

## 使い方

手の甲の図にある「○」が関節です。タップするたびに色が変わります。

| 表示 | 意味 |
| --- | --- |
| 白 | 記録なし |
| ピンク | やや痛い |
| 赤 | 痛みが強い |

3回タップすると白に戻ります。

関節は1本の指につき3か所あります。指先から順に第1関節（DIP）、第2関節（PIP）、第3関節（MP）です。親指だけは構造が違うので、第1関節（IP）、第2関節（MP）、付け根のCM関節を置いています。CM関節は親指の付け根の膨らんだ部分にあり、痛みが出やすい場所です。

日付は上部の矢印で前後に移動できます。日付欄をタップするとカレンダーから選べます。過去の日にさかのぼって記録することもできます。

画面下の「その日の気づき」には、朝のこわばりや動かしにくさなど、図では表せないことを自由に書けます。

## 気象データ

記録した日の気温（最高・最低・平均）、平均湿度、平均海面気圧を自動で記録します。起動時に、まだ気象データが入っていない日をまとめて取得します。

当日ぶんはその時点までの時間しか含まれないため「暫定」と表示され、日付が変わってから自動で取り直します。

「記録地域」で地域を変更できます。地名を入力すると候補が出るので選んでください。旅行や出張の際に切り替えると、その日以降の記録にはその土地の気象データが入ります。過去の記録の地点は変わりません。

気象データの出典は [Open-Meteo](https://open-meteo.com/) です。日本国内は気象庁（JMA）のデータが元になっています。

## データの保存について

**記録はお使いの端末のブラウザの中だけに保存されます。**

サーバーには一切送信されません。同じURLを他の人が開いても、その人には空のアプリが表示されるだけで、あなたの記録は見えません。

その代わり、次の点にご注意ください。

- **端末をまたいで共有されません。** パソコンとスマートフォンは別々の記録になります。
- **ブラウザの履歴やサイトデータを消すと、記録も消えます。** iOSのSafariには、しばらく開かないサイトのデータを自動削除する仕様もあります。

記録を守るため、また端末間で移すために、「バックアップ」ボタンを用意しています。押すと文字列が表示されるので、コピーしてメモアプリなどに保管してください。別の端末の「復元」に貼り付ければ、そのまま移せます。

「CSVで書き出す」を押すと、Excelに貼り付けられる形式で出力されます。日付・手・指・関節名・痛みの強さに加えて、その日の気温・湿度・気圧・地点が1行にまとまっているので、痛みと天候の関係を集計できます。

## iPhone・Androidで使う

ブラウザでURLを開き、共有メニューから「ホーム画面に追加」を選ぶと、アイコンから全画面で起動できるようになります。iPhoneの場合はSafariで行ってください。ほかのブラウザではこの機能が使えません。

## 注意

このアプリは記録を残すための道具であり、診断や治療方針を示すものではありません。痛みが続く場合や悪化する場合は、整形外科またはリウマチ科を受診してください。記録した図やCSVを持参すると、症状の経過を伝えやすくなります。

## 技術的なこと

HTMLファイル1枚だけで動きます。フレームワークもビルド工程もありません。手の図はSVGで直接描いています。保存にはブラウザのlocalStorageを使っています。

改変や再利用はご自由にどうぞ。
